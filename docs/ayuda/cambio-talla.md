# Cambiar la talla de una prenda

## Cómo hacer el cambio
En "Mis pedidos" elige la prenda y pulsa "Cambiar talla". Te enviamos la talla nueva y, a la vez, una etiqueta para devolver la que tienes. El cambio es gratuito.

## Si no hay stock
Si la talla que quieres está agotada, puedes elegir otra prenda o pedir el reembolso.

## Plazo
Tienes el mismo plazo que para una devolución: 30 días desde la entrega. La ropa interior y los bañadores no se pueden cambiar por motivos de higiene.
