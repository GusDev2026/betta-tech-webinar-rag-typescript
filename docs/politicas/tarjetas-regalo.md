# Tarjetas regalo

## Importes y formato
Las tarjetas regalo son digitales y se envían por email. Puedes elegir cualquier importe entre 10 € y 500 €. También puedes programar la fecha de envío, por ejemplo para un cumpleaños.

## Validez
Una tarjeta regalo es válida durante 2 años desde la fecha de compra. El saldo que no uses en un pedido se queda en la tarjeta para el siguiente.

## Cómo usarla
Introduce el código de la tarjeta en el último paso del pago. Si el pedido cuesta más que el saldo, puedes pagar la diferencia con tarjeta, PayPal o Bizum.

## Limitaciones
Las tarjetas regalo no se pueden devolver ni cambiar por dinero. No se pueden usar para comprar otras tarjetas regalo, y no se les pueden aplicar cupones de descuento.

## Si pierdes el código
Escribe a soporte desde el email con el que se compró la tarjeta. Si el código no se ha usado, te lo reenviamos.
