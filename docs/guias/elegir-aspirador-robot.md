# Guía: cómo elegir un robot aspirador

## Potencia de succión
Se mide en pascales (Pa). Para suelos duros bastan 2.500 Pa; si tienes alfombras o mascotas, busca 5.000 Pa o más.

## Navegación
Los robots con láser (LiDAR) hacen un mapa de la casa y limpian por habitaciones. Los que usan giroscopio son más baratos, pero limpian de forma menos ordenada.

## Base de vaciado
Una base de autovaciado vacía el depósito del robot sola, y solo tienes que cambiar la bolsa cada uno o dos meses.

## Nuestras recomendaciones
El Limpix R5 para pisos pequeños y el Limpix R9 Max para casas con mascotas.
