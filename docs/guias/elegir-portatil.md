# Guía: cómo elegir un portátil

## Memoria RAM
Para ofimática y navegación bastan 8 GB, pero recomendamos 16 GB para que el portátil dure varios años. Para edición de vídeo o programación, 32 GB.

## Almacenamiento
Elige siempre un disco SSD. 512 GB es el mínimo razonable hoy; si guardas fotos y vídeos, 1 TB.

## Tamaño de pantalla
13-14 pulgadas para llevarlo encima a diario, 15-16 pulgadas si lo usas sobre todo en casa.

## Nuestras recomendaciones
Para estudiar, el Voltix Air 14. Para trabajar, el Voltix Pro 16. Si buscas precio, mira los reacondicionados de grado A.
