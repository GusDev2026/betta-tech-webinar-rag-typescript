# Accesibilidad

## Compromiso
Queremos que cualquier persona pueda comprar en TiendaPepe. La web está diseñada para cumplir el nivel AA de las pautas de accesibilidad WCAG 2.2.

## Ayuda para comprar
Si tienes dificultades para usar la web, el equipo de soporte puede hacer el pedido por ti a través del chat o del email.

## Informar de un problema
Si encuentras una parte de la web que no es accesible, escríbenos a accesibilidad@tiendapepe.example.
